# Rounded camera viewport release check

Date: 2026-08-28  
Tested code commit: `dac6e7e`  
Target: Railway production, Mobile Safari-first

## Change

- Live camera, uploaded images and both deterministic demo scenes now render inside one inset rounded viewport on the black scanner canvas.
- Product box measurements use the new viewport itself, so the layout change does not introduce a second coordinate system.
- Source/demo controls remain outside the media card; recognition status remains inside it.
- Short phone landscape has its own compact safe-area layout.

## Known boundary

The web demo keeps automatic scanning and therefore intentionally does not copy the native shutter button. This release matches the camera framing and visual hierarchy without changing the scanner interaction model.
