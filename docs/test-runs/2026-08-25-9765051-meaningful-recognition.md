## Honest limits

- Open Food Facts is a secondary public source. Exact barcode records are preferred; text matches require brand, variant and pack-size agreement.
- A printed-label result requires one legible per-100 g/ml table containing kcal, protein and total sugars in the same view. Missing or ambiguous values remain neutral.
- The deterministic browser fixture proves the recovery interaction, not real-store recognition accuracy. Physical iPhone packaging, glare and latency checks remain user QA.
