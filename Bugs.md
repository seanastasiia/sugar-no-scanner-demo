# Bugs

This file tracks open limitations and only recent resolved regressions. Older history remains recoverable in Git.

## Open

- **Local production-mode Mobile Safari tests lack an HTTPS harness.** With `E2E_PRODUCTION=1`, production correctly marks the session cookie Secure, but local `http://127.0.0.1:3000` requests omit it and protected APIs return 401. The normal development-server suite is the supported local acceptance command; the built deployment must also be smoke-tested over Railway HTTPS. Do not weaken production cookie security to make this optional local mode pass.
- **Personal Shelf Rank is an isolated-preview, unvalidated preference pilot.** 198 exact-source observations yield 64 complete scores; missing fiber and unrecognized ingredient wording are the main gaps. Dairy desserts have no calibration examples yet. Store category mistakes are possible, and two scored SKUs are not representative of a whole market. No public healthy/unhealthy or NOVA claim is made. A review of real packages and category ordering is required before broad rollout. The old Shelf/Checkout demos may have no complete composition records; the dedicated New rating demo now provides five exact catalog examples without needing a shop visit.
- **The isolated preview has process-only online cache.** It deliberately has no Supabase or Amplitude credentials, protecting existing production/staging data. Restarting the preview loses its online cache, not its checked-in catalog/evidence; repeated lookups can cost provider requests again. Durable preview storage requires a separately approved Supabase target.
- **Ingredient-free demo categories can be misleading.** Live preview QA places the cookie-flavoured ICONFIT bar in `Cookies & wafers`, based on the legacy fallback category. It has no exact composition observation and remains unscored, so no incorrect numeric rank is produced. Exact category coverage/wording needs review before expanding the pilot; legacy demo category inference is not verified ingredient evidence.
- **Shelf-pilot managed storage is not yet deployed.** The additive Supabase migration and non-destructive seed/readback script are prepared but have only been dry-run locally. Runtime is functional from the checked-in evidence with bounded optional Supabase reads; production ingestion and retailer permission remain separate gates.
- **Historical catalog snapshots do not yet contain carbohydrates.** The app now supports exact source-backed carbohydrates per 100 g or 100 ml, but existing checked-in rows omit the field until their next retailer, Open Food Facts or grounded-source refresh. Sugar.no fit remains available from protein and total sugar and is not recalculated.
- **Latvia coverage is not universal.** Private labels, unreadable variants and products without an exact cited per-100 table can remain unresolved. They must not receive a guessed fit.
- **Physical-store accuracy is not validated.** Packaging glare, low light, distance and a moving checkout belt need a real-store benchmark.
- **Shelf-price association needs a benchmark.** Ambiguous labels stay hidden; a package number, deposit or unrelated nearby tag must not become the product price.
- **Rimi/Livin/Livinn snapshots are not market-wide.** Rimi is intentionally limited to seven selected food and drink categories (6,822 complete rows from 7,617 pages); Livin Latvia contributes 6 complete rows; Livinn Lithuania contributes 2,489 edible identities, of which 1,855 have complete Fit nutrition. Recurring production reuse still requires retailer permission.
- **Open Food Facts coverage is still bounded and community-maintained.** The checked-in Latvia layer contains 500 complete records; multilingual aliases prevent known-language names from being discarded. A separate Lithuania/Belarus bulk layer and importer are ready, but the large official export still needs an approved durable data job and quality review.
- **Retailer snapshots age.** Checked-in product and nutrition indexes are reproducible discovery snapshots, not real-time stock or price guarantees.
- **Grounded nutrition can be unavailable.** Identity appears first; exact internet enrichment is background-only, requires a readable pack size or barcode, and its final grounded-search fallback defaults to 12 seconds.
- **The investor URL is public.** Direct entry intentionally has no viewer access challenge. The silent same-site session, origin checks and rate limits reduce bare API abuse but are not authentication; restore an explicit identity or access gate before sharing restricted retailer data broadly.
- **Railway config-as-code needs migration before 1 December 2026.** The current `railway.json`/`railway.toml` deployment still works, but Railway now recommends `.railway/railway.ts` and prints a deprecation warning during deploys.
